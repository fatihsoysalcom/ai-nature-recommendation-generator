# AI Nature Recommendation Generator

This Python script simulates the core AI recommendation feature of the Wander app. It takes user input for weather and mood to suggest a suitable outdoor activity, demonstrating how AI can encourage nature connection.

## Language

`python`

## How to Run

1. Save the code as `wander_recommender.py`.
2. Run from your terminal: `python wander_recommender.py`
